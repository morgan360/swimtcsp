Reconciliation Guide

Status Categories

  • Matched — Order amount matches the BOIPA payment notification amount.
  • Mismatch — A notification exists but the amount differs from the order.
  • No Notification — The order has a TxId but no webhook notification was recorded. Common for orders placed after the Dec 2025 BOIPA migration. Use Verify to confirm with BOIPA.
  • No TxId — No transaction ID was saved for this order. The payment may have been abandoned or processed outside BOIPA.

Action Buttons

  • Verify — Contacts the BOIPA API to check if the transaction was captured. If confirmed, marks the order as verified and fills in the BOIPA amount and difference columns.
  • Details — Expands the row to show all payment notification records stored for this order, including transaction IDs, statuses, amounts, and source (webhook or payment response).

Columns

  • BOIPA Amt — The payment amount recorded by BOIPA (from notifications or API verification).
  • Diff — Difference between the order amount and BOIPA amount. Should be €0.00 for correct payments.
