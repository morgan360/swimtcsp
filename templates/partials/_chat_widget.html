{% comment %} SplashBot as an in-page panel rather than a new tab. The panel deliberately reuses the element ids static/chatbot/chat.js already binds to — chat-container, chat-log, chat-input, chat-send, send-text, send-spinner — so the sending, CSRF, HTML-vs-typed reply handling and error paths are the same code the full-page chat uses. Nothing about the backend changes. That shared contract means only one #chat-container may exist per page, so the standalone chat pages override {% block chat_widget %} to leave this out. {% endcomment %}
